# nemdull.com

nemdull（ねむだる）のポートフォリオです。公開先は https://www.nemdull.com/ 。

Vite、React 19、TypeScript、Tailwind CSS 4 で作っています。アニメーションのライブラリは入れておらず、動きは CSS と Canvas だけです。

## 見た目の考え方

このサイトは、2 つの声でできています。

- **人の声** … ベタ塗りの色面に、大きな見出し（Dela Gothic One）。眠そうに傾いていて、丸い
- **機械の声** … ドット文字（DotGothic16）の札、電光掲示板、文字でできた星空。まっすぐで、四角い

人が書いたものを、機械がその場で確かめて回る、という作りです。見出しの横や「できること」の下に出ている小さな札は飾りではなく、下に書いた点検の、本物の結果です。

ページは「部屋」に分かれていて、地の色が 夜（群青）→ 黄 → 紺 → 月（白）→ 藤 の順でくり返します（`src/content/rooms.ts`）。

## このサイトがやっていること

- **開くたびに、自分で自分を点検する。** 「発進前チェック」の部屋が、本物の DOM を見て 7 項目を確かめます（見出しがあるか、リンクがぜんぶ https か、行き先が決めたサイトだけか、「できること」に根拠が付いているか、など）。結果は、部屋の上の電光掲示板にも流れます
- **わざと壊して、点検が本当に見つけられるかを試せる。** 「隕石をぶつける」を押すと、見出し・アイコン・リンク・根拠のどれかが実際に壊れ、点検が落ちます。「修理する」で元に戻ります
- **同じ点検を、ビルドの前にもかける。** `npm run build` の最初に `scripts/check-content.mjs` が走り、問題があればビルドが止まります
- **スクロールで、見出しの「。」に飛び込む。** いちばん上の画面はスクロールのあいだ留まり、文字が 1 つずつ飛んでいって、最後の「。」の明かりが広がり、その奥に自己紹介の部屋が見えてきます。自己紹介は、スクロールに合わせてカーソルが読み進めます
- **「動きを減らす」設定に従う。** 端末でこの設定がオンなら、アニメーションはすべて止まり、いちばん上の画面も留めずに上から順に並びます。止まっているかどうかも点検の 1 項目です

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm run check    # 内容の点検だけ
npm run build    # 内容の点検 → 型チェック → ビルド
npm run preview  # ビルド結果の確認
npm run lint
npm run test:e2e # 画面を実際に開いて確かめるテスト（先に npm run build）
npm run og       # 共有したときに出る画像（public/og.png）を作り直す（先に npm run build）
```

Node.js は 20.19 以上、または 22.12 以上。

## 文言やリンクを変えるとき

載せる内容は `src/content/profile.json` の 1 か所にまとめてあります。文言・リンク・経歴・資格は、ここだけ直せば画面に出ます。

`links`（GitHub・X・Zenn・Qiita など、自分のほかのページ）は、画面のリンクになるだけでなく、ビルドのときに検索エンジン向けの情報（schema.org の Person の `sameAs`）としても埋め込まれます。`robots.txt` と `sitemap.xml` も、同じ JSON から作っています（`vite.config.ts`）。

新しいサイトへリンクを張るときは、先に `src/content/allowed-hosts.json` に足します。ビルド前の点検と、ページを開いたときの点検の両方が、この一覧を見ています。

部屋の並びと色は `src/content/rooms.ts` にあります。目次の札と、上の帯の「いまここ」（`#works` など）も、この一覧から作っています。

## 点検の中身

| 見ていること | ビルドの前 | ページを開いたとき |
| --- | --- | --- |
| 「できること」の各行に根拠があるか | 止める | 落ちる |
| リンクが https か | 止める | 落ちる |
| リンク先が、決めた一覧の中にあるか | 止める | 落ちる |
| 見出し（h1）が 1 つあって、中身があるか | — | 落ちる |
| アイコンの画像が読み込めているか | — | 落ちる |
| 画面の横にはみ出していないか | — | 落ちる |
| 「動きを減らす」設定を守っているか | — | 落ちる |
| 書体のファイルに入っていない文字が無いか | 警告 | — |

ページを開いたときの点検は `src/systems/preflight.ts` にあります。結果は、点検盤のほかに、確かめている物のそばの札（`src/components/machine/CheckNote.tsx`）にも出ます。

## テスト

`e2e/portfolio.spec.ts` が、Playwright で画面を実際に開いて確かめます。PC（Chrome）と Android のスマホ幅で走り、CI ではさらに iPhone の Safari と同じ描画エンジン（WebKit）でも走ります。

- 開くと見出しが出て、点検が 7 項目とも通る
- **隕石を 5 回ぶつけると、5 種類の壊れ方をすべて見つけ、修理で元に戻る**（壊したのが 1 か所なら、落ちるのも 1 項目だけ）
- スクロールすると、最後の「。」の明かりから自己紹介の部屋が広がり、読み進めて、戻せば元どおりになる
- 機械の札に、点検の結果がそのまま出る
- 目次は、札を選ぶとその部屋へ移って閉じる。Esc でも閉じて、フォーカスが戻る
- 「動きを減らす」設定では、動き続けるものが無く、いちばん上の画面も留まらない
- 幅 320 / 390 / 768 / 1280 px で、横にはみ出さない
- 外へのリンクは、ぜんぶ https で、決めたサイトだけ
- sf-meter のメーターの項目を押すと、その実現度を指す
- 読みやすさの自動チェック（axe。色の濃さの差、ボタンやリンクの名前、見出しの順番など）で、問題が見つからない

初めて動かすときは、ブラウザーを入れます。

```bash
npx playwright install chromium
npm run build && npm run test:e2e
```

プルリクエストと main への push で、GitHub Actions が lint・ビルド・このテストを走らせます（`.github/workflows/ci.yml`）。

## 書体

Dela Gothic One（見出し）、Zen Kaku Gothic New（本文）、DotGothic16（札・電光掲示板・星空）から、このサイトで使う文字だけを取り出して `src/assets/fonts/` に置いています。どれも SIL Open Font License 1.1 です。文言に新しい漢字を足したら、作り直します。

```bash
pip install fonttools brotli
npm run fonts
```

作り直さなくても表示は壊れません（足りない文字だけ、端末の書体になります）。sakujiru の欄で描いている「作字」の輪郭（`src/content/lettering.json`）も、このとき一緒に作られます。

電光掲示板は、DotGothic16 が 16×16 のマス目でできた書体であることを使って、字のドットをそのまま拾って点にしています（`src/components/machine/Led.tsx`）。

## 構成

```
src/
├─ content/        # profile.json（載せる内容）、rooms.ts（部屋の並びと色）、allowed-hosts.json（リンクしてよいサイト）、型
├─ systems/        # 点検の定義（preflight.ts）と、その状態を配る Provider
├─ components/
│  ├─ chrome/      # 画面に付いてくるもの：上の帯、目次、文字の星空、隕石
│  ├─ machine/     # 機械の声：点検の札、電光掲示板
│  ├─ hero/        # いちばん上の画面：見出し、月（アイコン）、スクロールの段取り
│  ├─ intro/       # 「。」の奥にある、自己紹介の部屋
│  ├─ preflight/   # 発進前チェックの部屋（電光掲示板と点検盤）
│  ├─ works/       # つくったもの（メーター、作字の線画）
│  ├─ sections/    # できること、仕事、書いたもの、道具、資格、連絡
│  └─ ui/          # 部屋の枠、リンク
├─ lib/            # スクロールの配信、画面に入ったかのフック、日本語の文の区切り
├─ styles/         # 見た目。base（色と共通の部品）・chrome・hero・rooms・sections・motion（動きはここに 1 か所）
├─ assets/         # 画像と書体
└─ index.css       # 書体と色の定義、styles/ の読み込み
scripts/
├─ check-content.mjs  # ビルド前の点検
├─ subset-fonts.py    # 書体の作り直し
└─ og.mjs             # 共有したときに出る画像の作り直し
e2e/
└─ portfolio.spec.ts  # 画面を実際に開いて確かめるテスト（Playwright）
```
